# ADR 0004 — Nome do produto: FragLens

- **Status:** aceita
- **Data:** 14/09/2026

## Contexto

O nome inicial "CS Watch" colide com produtos de CS2 já existentes: **cswatch.gg** (reputação e detecção de trapaças, com API pública) e **cswat.ch** (estatísticas de jogadores).

## Decisão

- Produto: **FragLens**
- Comando: `fraglens`
- Pacote npm: `fraglens` (livre em 14/09/2026)
- Escopo interno dos pacotes do monorepo: `@fraglens/*`
- Slogan: **Inteligência de jogadores de Counter-Strike 2 direto no terminal.**

## Motivo

Não foi encontrado produto de CS2 com esse nome, não usa marca de terceiros ("CS2", "Leetify") e não lembra concorrentes diretos.

## Alternativas consideradas

- **FragScope / RoundScope:** livres, mas lembram o scope.gg (concorrente de análise de CS2).
- **ClutchLens:** já existe (clutchlens.tech).
- **Cs2Insight:** usa "CS2", marca da Valve.
